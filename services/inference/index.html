AZYL.inference

Your models, on your hardware.

Run local models on your own GPU without the command line. AZYL.inference installs and runs a llama.cpp-based engine for you, loads models when they’re asked for and lets them go when they’re not, and puts every setting that matters on one page, with a friendly face on whatever is running.

Written in Rust · one 7 MB binary · llama.cpp-based engine underneath · nothing leaves your machine

Read on
The problem

Local models are free to run. Let’s make running them simple and clean.

One tool wants to own your desktop. The other wants environment variables. The context window hides in a Modelfile, concurrency in a variable you set before the server starts, and what’s using your VRAM in a command you have to remember. Your agents reach the model through an OpenAI endpoint that can’t even say how much context it needs.

AZYL.inference runs the engine for you and puts every one of those settings on a page, where you can see them, change them, and watch what they do.

What it does

Your GPU, run like a small server.

A llama.cpp-based engine does the inference. AZYL.inference does everything around it: installing it, keeping it running, deciding what’s in memory, and showing you, at a glance, what it’s doing.

07 · At a glance

A status page you can leave open

The AZYL dot sleeps when nothing is loaded, raises its shield while a model loads, waits with big eyes when one is ready, and gets busy while it generates. The numbers are right underneath.

New in 1.1

Find a model that fits. Run one bigger than your GPU.

Search Hugging Face from the app and see, before you download, whether each quantization fits on your GPU for the context window and parallel requests you run. Then let a second engine take the one model that never would.

Hugging Face search
Lists every quantization of a GGUF repository with its size, says whether it fits wholly on your GPU, partly or not at all, and marks the best fit. Only your search words go to huggingface.co.
Avalona second engine
Runs Qwen3.8-Flash-Next, a 107B mixture-of-experts model, with its experts in RAM and the busiest on the GPU. It shows up with your other models, loads in about 20 seconds, and takes the GPU in turns with the main engine.
One address for every model
An OpenAI-compatible endpoint that sends each request to the engine that runs its model, and hands the GPU over on the way when it needs to.
Embeddings on the CPU
A second, GPU-less llama.cpp instance keeps an embedding model loaded for apps like AZYL.memory, so a search never waits for a model swap. About 8 ms per query.
Speculative decoding
Models with a built-in MTP layer get a draft-length setting: on a 27B model, about 36% faster prose and 66% faster code on the same card.
Vulkan or ROCm
Pick the GPU backend the engine uses, from the same engine settings page.
Under the hood

Written in Rust. Small, quiet, and in charge of its engine.

A front-end that supervises a GPU server has to be the steady part. AZYL.inference is one small native binary that starts in milliseconds, holds no runtime, and cleans up after itself.

Binary

One 7 MB file

An async Rust server with the web app built in. Installed as a systemd user service, opened as its own window.

Supervision

It owns the engine

The engine runs in its own process group, restarts after a crash, and stops with the app, even if the app is killed outright.

Installs

Verified downloads

The engine comes from its GitHub release, is checked against the published SHA-256, and is swapped in only once it’s whole.

Privacy

Local by default

The app and the engine listen on this computer only, and nothing calls out to the cloud. Your prompts stay on your GPU.

Remote

Your tailnet, your login

Remote access goes through tailscale serve, and every request must carry an allowed Tailscale identity.

Web app

Hardened by default

A DNS-rebinding guard, a custom header on every change and a strict content policy, so a web page can’t drive your models.

Measured on the machine in the screenshot: a 27B model (Q4_K_M) loads in about 12 seconds and generates around 37 tokens per second on a Radeon RX 7900 XTX; importing its 17 GB file from LM Studio takes under a minute.
