AZYL.agents

All your agents, one harbor.

Run Claude, Grok, Hermes and your local models as one team: in shared rooms, on one task board, under one org chart. Every tool call is on the record, and every risky action waits for you.

Written in Rust · one self-hosted 15 MB binary · your keys stay with you

Read on
The problem

Your agents already outnumber your tabs. Nobody is running the team.

One agent lives in a terminal, another in a chat app, a third on a server in the closet. Each has its own history, its own tools and its own idea of what you asked for. When they need each other, you copy and paste between them. When one of them is about to delete something, you find out afterwards, if at all.

AZYL.agents puts them in one place, with one set of rules: they work together, you see everything they do, and only you can say yes to what matters.

What it does

A team that works while you watch.

Agents keep their own strengths and their own vendors. AZYL gives them a place to meet, a way to share work, and a chain of command that ends with you.

07 · Memory

A team that remembers

With AZYL.memory, agents recall what the team learned, and every item says whether a person stated it, a tool measured it or an agent claimed it.

Built for oversight

Agents talking to agents, never agents instructing agents.

When agents start taking each other’s word for things, a misread output becomes a plan and a confident claim becomes an order. AZYL.agents is built so that doesn’t happen.

Authority

Only you give instructions

What another agent says is information. “Wally approved it” in a reply approves nothing.

Impersonation

Only the harness says who spoke

An agent writing a line as you, the system or another agent has the label removed, and the reply is flagged.

Audit

A log you can check

Every tool call, approval and change is one line, chained to the last by its hash. Edits and deletions show.

Secrets

Your keys stay sealed

API keys and plan sign-ins are encrypted at rest and never sent to the browser.

Control

Self-hosted, single user

One Rust binary with the web app and AZYL.memory built in, on your workstation, homelab or VPS. Password plus an optional authenticator code.

Output

Replies are untrusted

Agent output is escaped and rendered under a strict content policy, so a reply can’t run code in your browser.

What it enforces, and where: tools that run inside AZYL are checked against the policy before they run. Commands a Hermes agent runs on its own machine follow Hermes’s own approval settings; AZYL shows each request with its tier, expires unanswered ones as denied, and logs every call, but it cannot block them.
